# PINNING POLICY (per AAP Sec 0.7.7 "Coding and Quality Standards"):
#   - Every dependency pinned to an exact version with `==`.
#   - No `latest`, no `^`, no `~`, no `>=` ranges.
#   - Transitive dependencies are pinned explicitly to prevent silent
#     production drift between deploys (Werkzeug, MarkupSafe, cryptography,
#     httpx, urllib3, jiter, etc.).
#   - Updates flow through Dependabot PRs accompanied by a decision-log
#     entry in docs/decision-log.md (per AAP Sec 0.7.5 "Explainability rule").
#
# CRITICAL VERSIONS (per AAP Sec 0.3.2 and 0.2.4 web-search verification):
#   - Flask     == 3.1.3   (Feb 2026 security release)
